01 / The task

Problem

I start with a molecule's fragmentation spectra. I need to recover its 2D structure.

I use tandem mass spectrometry (MS/MS): a molecule breaks into fragments, and the instrument measures their mass-to-charge ratios and intensities. I use these clues to rank up to 25 candidate structures.

How I measure success

I use mean reciprocal rank at 25, or MRR@25. A correct answer at rank 1 earns 1; at rank 2, it earns 1/2. A missing answer earns 0. I average over molecules. Matching uses tautomer-canonical connectivity, without stereochemistry.

Class 1

A reference spectrum exists

I can search the supplied spectral library for the same structure.

Class 2

The structure is known

I search structure databases without a reference spectrum in the supplied library.

Class 3

The structure is new

I need to generate a structure outside the reference databases.

02 / The method

My approach

I built my own retrieval and ranking pipeline. I then integrated and extended public community work.

  1. 01

    I built the first pipeline

    I combined spectral library search with analog evidence. I indexed 91 million PubChem structures by mass and connectivity. I added a LightGBM reranker and a contrastive spectrum-to-structure model trained with hard negatives from the same mass window.

    I retrained the public spectrum-to-structure model on the full training set, with 300 timsTOF molecules held out by structure. It ranks the true structure first among about 50 isomers for 84% of them, against 63% for the public model. It did not improve the public leaderboard, which taught me as much as the offline gain.

    Best public score from my own pipeline: 0.283.

  2. 02

    I integrated and extended an open-source pipeline

    I reproduced a community baseline at 0.451. I tested my contrastive signal, combined rankings from two public lineages, and evaluated later community extensions. I kept the authorship and asset licences explicit.

    The later 0.479 and 0.480 milestones reproduce community pipelines credited below.

  3. 03

    I added an external spectral library

    I built a compact library from newer GNPS, MassBank, and MSnLib releases. The organiser permits newer versions of the sources used in the training data. I use this library to look for reference spectra missing from the original snapshot.

    This extension is under evaluation. I do not assign it a score gain yet. Organiser clarification.

04 / The lessons

What I learned

I need validation that reflects both the model's history and the test distribution.

I run one change per submission

I ran more than 70 submissions as controlled experiments. Each one changes a single thing against a named reference, and I keep control runs to check that a copy reproduces its score.

I split by molecule

I keep all spectra of a validation structure out of my model training. I group by the matching structure key, including equivalent tautomers. A spectrum-level split would let the same molecule appear on both sides.

I audit pretrained models too

I found that a clean split in my own code did not guarantee clean model features. Some community components were trained on the full competition training set. My held-out molecules could therefore already be known to those models. I also suspected prior exposure in third-party simulators; that explanation remained a hypothesis.

I check which molecules my validation represents

I initially relied on well-documented natural products. I inferred from targeted submissions that class 2 included more PubChem-only structures than my validation did. A rule that helped offline lost 0.057 on the public board when it demoted those candidates.

I test whether offline gains transfer

I rebuilt an evaluation with models that had not seen the held-out molecules. I also removed the correct structure's training-set status in the class 2 simulation. Neither change made learned reranking gains transfer reliably. The revised benchmark still predicted gains near 0.05 for two rerankers that lost about 0.08 on the public board.

I cannot attribute the whole gap to model exposure. I treat distribution mismatch as unresolved, and public leaderboard feedback as provisional evidence.

I reproduce a score before adopting it

I reran a public pipeline advertised at 0.481. My unchanged control scored 0.469. I could not establish the cause; input or output versions were a possible explanation. I kept 0.480 as my best reproduced score.
